# Arcade System - releases

This repository is the version feed for the Arcade System. It holds no files
of the system itself; the update packages are hosted elsewhere.

Each release is one system version:

- **Tag**: the version, `vYY.MM.DD` (for example `v26.09.06`).
- **Body**: the change log shown to users. It becomes the user's local
  `update-log.txt` after the update is applied.

The Arcade System Updater reads the newest release to decide whether a
system update is available.
